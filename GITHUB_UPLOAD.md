# GitHub Upload Guide

This folder is a **clean, publication-ready export** of the hybrid QPSO–SQP chemo-immunotherapy code associated with doi:[10.3934/dcdsb.2026072](https://doi.org/10.3934/dcdsb.2026072).

## What is included

- Canonical solver (`src/`)
- Case configs and pinned reproducibility settings (`configs/`)
- One-command reproduction (`scripts/reproduce_paper.m`)
- Paper PDF (`paper/published_paper.pdf`)
- Reference Table 3 metrics (`results/reference/table3_paper.csv`)
- Author reference EPS figures (`results/figures/Case_*.eps`, etc.)
- Archived legacy code (`archive/`) for provenance only

## What is excluded (regenerable)

- `results/*.mat` solution files
- `results/figures/fig*.png` / `fig*.eps` (generated by reproduction scripts)
- Duplicate root-level PDF copy
- `.DS_Store`, `.asv`, editor temp files

## Before first push

1. Update `CITATION.cff` → set `repository-code` to your GitHub URL.
2. Run locally (MATLAB R2024a recommended):
   ```matlab
   run('scripts/validate_repo.m')
   run('scripts/reproduce_paper.m')
   reproduce_paper_pipeline('freeze_reference', true);  % optional
   ```
3. Optionally commit `results/reference/canonical_outputs.mat` after freezing.
